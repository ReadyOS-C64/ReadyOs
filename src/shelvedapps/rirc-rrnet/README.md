# ReadyIRC RR-Net (shelved)

This is the earlier RR-Net/IP65 version of ReadyIRC. It is behind the active
C64 Ultimate ReadyIRC implementation in `src/apps/readyirc`, particularly in
IRC behavior, user experience, resilience, and integration with current
ReadyOS facilities.

The code is retained only as a reference for possible future non-Ultimate
network-adapter work. It is deliberately excluded from every normal build,
launcher catalog, disk image, EasyFlash payload, release package, and ReadyOS
SKU. No `rirc-rrnet.prg` should be produced or shipped by the current build.
